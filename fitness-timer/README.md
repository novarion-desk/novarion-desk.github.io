# Fitness-Timer

Intervall-Timer für Warm-up, Training und Cooldown. Eine einzige HTML-Datei, ohne externe Abhängigkeiten, installierbar und offline nutzbar.

- Live (GitHub Pages): https://novarion-desk.github.io/fitness-timer/
- Daten (Abläufe, Verlauf, Einstellungen) liegen nur im Browser auf dem Gerät (`localStorage`), Sicherung unter «Mehr».
- Kein Login, kein Firebase, kein Tracking.

| Datei | Inhalt |
|---|---|
| `index.html` | Die App |
| `manifest.webmanifest`, `icons/` | Installation als App |
| `sw.js` | Offline-Betrieb (Service Worker) |
| `ARBEITSWEISE.md` | Notizen für die Weiterarbeit |

Hinweis: Die Übungsbeschreibungen sind allgemeine Hinweise, keine Trainingsberatung.
